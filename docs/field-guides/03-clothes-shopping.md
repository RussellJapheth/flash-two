## 1. Core Clothing Nouns & Measure Words

In Chinese, different garments take distinct measure words:

| Item     | Pinyin   | Meaning           | Measure Word      | Example Chunk                       |
| :------- | :------- | :---------------- | :---------------- | :---------------------------------- |
| **衣服** | yīfu     | Clothes (general) | **件** (_jiàn_)   | 一件衣服 (yí jiàn yīfu)             |
| **衬衫** | chènshān | Shirt / blouse    | **件** (_jiàn_)   | 这件白衬衫 (zhè jiàn bái chènshān)  |
| **外套** | wàitào   | Jacket / coat     | **件** (_jiàn_)   | 那件蓝色外套 (nà jiàn lánsè wàitào) |
| **裤子** | kùzi     | Pants / trousers  | **条** (_tiáo_)   | 这条黑裤子 (zhè tiáo hēi kùzi)      |
| **裙子** | qúnzi    | Skirt / dress     | **条** (_tiáo_)   | 一条裙子 (yì tiáo qúnzi)            |
| **鞋**   | xié      | Shoes (paired)    | **双** (_shuāng_) | 一双运动鞋 (yì shuāng yùndòngxié)   |

## 2. Size Classification (S/M/L/XL)

| Size             | Hanzi      | Pinyin   | Inquiries                                        |
| :--------------- | :--------- | :------- | :----------------------------------------------- |
| Small (S)        | **小号**   | xiǎohào  | `有小号的吗？` (Do you have small?)              |
| Medium (M)       | **中号**   | zhōnghào | `我觉得中号最合身。` (I think medium fits best.) |
| Large (L)        | **大号**   | dàhào    | `这件衣服有大号吗？` (Is there a large?)         |
| Extra Large (XL) | **特大号** | tèdàhào  | `有特大号的外套吗？` (Do you have XL?)           |

## 3. The Fitting & In-Store Dialogue

1. **Asking to try on**:
   - `我可以试穿一下吗？` (_Wǒ kěyǐ shìchuān yíxià ma?_ — May I try this on?)
2. **Finding the fitting room**:
   - `请问试衣间在哪里？` (_Qǐngwèn shìyījiān zài nǎlǐ?_ — Where is the fitting room?)
3. **Evaluating fit**:
   - **合身** (_héshēn_): Fits well (`非常合身`)
   - **宽松** (_kuānsōng_): Loose / roomy (`喜欢宽松一点的`)
   - **紧** (_jǐn_): Tight (`腰部有点紧`)
4. **Requesting a fresh item**:
   - `这件有点脏，能换一件吗？` (_Zhè jiàn yǒudiǎnr zāng, néng huàn yí jiàn ma?_ — This has a mark, could I swap for a clean one?)
5. **Inquiring on discounts & price**:
   - `请问今天打折吗？` (_Qǐngwèn jīntiān dǎzhé ma?_ — Is this discounted today?)
   - `老板，能不能便宜一点？` (_Lǎobǎn, néng bu néng piányi yìdiǎnr?_ — Can you make it a bit cheaper?)
