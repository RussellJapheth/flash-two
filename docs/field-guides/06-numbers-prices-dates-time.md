## 1. Place-Value Zero Rule (零 · líng)

In spoken Chinese, **零** is spoken **only once** for consecutive missing places inside a number:

| Number   | Reading                          | Reason                                    |
| :------- | :------------------------------- | :---------------------------------------- |
| **105**  | 一百**零**五 (_yì bǎi líng wǔ_)  | Missing tens place requires 零            |
| **1005** | 一千**零**五 (_yì qiān líng wǔ_) | Even with 2 zeroes, say 零 only once      |
| **150**  | 一百五(十) (_yì bǎi wǔ_)         | Trailing zeroes are omitted or read as 十 |

## 2. Chinese Currency Units: Spoken vs Written

| Value     | Written / Formal | Spoken / Colloquial | Example                |
| :-------- | :--------------- | :------------------ | :--------------------- |
| 1.00 Yuan | **元** (_yuán_)  | **块** (_kuài_)     | 五块钱 (5 kuai)        |
| 0.10 Yuan | **角** (_jiǎo_)  | **毛** (_máo_)      | 五毛钱 (50 cents)      |
| 0.01 Yuan | **分** (_fēn_)   | **分** (_fēn_)      | 两块零五分 (2.05 yuan) |

## 3. Mobile Payments & Shopping Phrases

China is largely cashless; you will use QR codes for transit, dining, and shops:

- `请扫码付款。` (_Qǐng sǎomǎ fùkuǎn._ — Please scan the QR code to pay.)
- `微信支付` (_wēixìn zhīfù_ — WeChat Pay) / `支付宝` (_zhīfùbǎo_ — Alipay)
- `一共多少钱？` (_Yígòng duōshao qián?_ — How much in total?)
- `找钱` (_zhǎoqián_ — give change) / `零钱` (_língqián_ — small change)
- `小票` (_xiǎopiào_ — receipt)

### Discount Math: "打折"

Chinese discounts indicate the percentage you **pay**, not what is taken off:

- **打八折** (_dǎ bā zhé_): Pay 80% = **20% off**
- **打五折 / 半价** (_bànjià_): Pay 50% = **Half price**
- **买一送一** (_mǎi yī sòng yī_): Buy one get one free
